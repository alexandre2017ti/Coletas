# Aplicativo de Entregas e Coletas

Plataforma para conectar estabelecimentos a entregadores disponíveis na cidade, com distribuição automática de entregas, acompanhamento em tempo real, agrupamento de rotas e controle de licença e capacitação dos entregadores.

## Documentação obrigatória

Antes de implementar ou alterar qualquer funcionalidade, leia:

- [docs/PLANO-DO-PROJETO.md](docs/PLANO-DO-PROJETO.md)
- [docs/REGRAS-DE-ORGANIZACAO.md](docs/REGRAS-DE-ORGANIZACAO.md)
- [docs/DECISOES-ARQUITETURAIS.md](docs/DECISOES-ARQUITETURAIS.md)
- [docs/DESENVOLVIMENTO.md](docs/DESENVOLVIMENTO.md): instalação local, execução, testes e limites de validação.

Toda mudança deve seguir o procedimento definido em `docs/REGRAS-DE-ORGANIZACAO.md`.
